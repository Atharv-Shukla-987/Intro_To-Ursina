A 3d game made in python language using a library called ursina { first time using it so name is ursina}  . 
It is action shooter game , something like real life where u can not win and will loose eventually or just leave because u are bored as hell

## Controls

Movement -------- 
Forward - press W
Backward - press S
Right - press D
Left - press A

crouch to heal yourself - press Shift

fire bullets - Click Mouse left

To Change Weapon - Mouse Scroll


## How to play

You just need to download the main.zip from here or from https://atharv-shukla-987.itch.io/death-trap  and after exracting it , run the the main executable file and after it you are ready to play !!!
